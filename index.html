FAQ

GOT QUESTIONS?

What is WHO'S LYING?

A multiplayer social deduction party game where most players know a secret word and one hidden liar tries to blend in.

How do players join?

The host creates a room and shares a room code. Other players enter the code to join the match.

Does the liar automatically lose if caught?

No. The liar gets one final chance to guess the secret word. A correct guess steals the round.

Where will the game be available?

The first public release is being prepared for Google Play. Additional platforms can be added later.
